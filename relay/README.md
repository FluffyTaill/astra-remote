# Ретранслятор Phone Remote

Даёт телефону достать до ПК откуда угодно — без Tailscale и без открытых портов. Это Cloudflare Worker:
ПК и телефон сами подключаются к нему, а он только передаёт байты между ними. Внутри идёт тот же HTTPS
с сертификатом ПК, что и дома, поэтому ретранслятор не видит ни команд, ни файлов, ни чата и не может
выдать себя за ПК.

Ретранслятор у каждого свой: общего нет. Это бесплатно и занимает минут пять.

## Развернуть

### Кнопкой

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/FluffyTaill/astra-remote)

1. Нажми кнопку (она есть и на странице плагина в Astra), войди в Cloudflare или заведи бесплатный аккаунт, подтверди.
2. Cloudflare создаст копию репозитория у тебя на GitHub и развернёт ретранслятор. Если он покажет форму
   «Клонировать репозиторий» и попросит адрес — вставь `https://github.com/FluffyTaill/astra-remote`
   (без `/tree/...` в конце) и нажми «Развернуть».
3. Скопируй его адрес (`https://astra-remote-relay.<твоё-имя>.workers.dev`) на страницу Phone Remote в Astra —
   карточка «Вне дома: свой ретранслятор» → «Сохранить».
4. Открой приложение на телефоне дома, в той же сети, что ПК: оно само узнает адрес.

### Вручную

Нужен [Node.js](https://nodejs.org). В этой папке:

```
npx wrangler login
npx wrangler deploy
```

Если Cloudflare пишет «You need a workers.dev subdomain» — открой один раз в панели Cloudflare раздел
Workers & Pages, поддомен создастся сам, и повтори `deploy`.

## Закрыть для чужих

Ретранслятор и так не пускает чужих к твоему ПК, но кто узнает его адрес, сможет подключить к нему свой
ПК и тратить твой суточный лимит. Чтобы этого не было, впиши номер своего ПК (он на странице Phone Remote,
под карточкой ретранслятора) в секрет `ALLOWED_PCS`.

Проще всего в панели Cloudflare: Workers & Pages → `astra-remote-relay` → **Settings → Variables and Secrets →
Add** → тип **Secret**, имя `ALLOWED_PCS`, значение — номер ПК → **Deploy**.

Или из командной строки, в этой папке:

```
npx wrangler secret put ALLOWED_PCS
```

и вставь номер (несколько ПК — через запятую). После этого ретранслятор пускает только эти ПК и телефоны к ним.

## Лимиты

Бесплатный план Cloudflare Workers — 100 000 запросов в сутки (сброс в 03:00 по Москве). Пульт, чат и
кнопки тратят десятки запросов в день, снимок экрана с автообновлением — порядка тысячи в час. Если лимит
кончится, вне дома приложение не достучится до сброса; дома оно работает напрямую, без ретранслятора.

Ретранслятор сам ограничивает каждый ПК: не больше 24 открытых подключений телефона и 120 новых в минуту.
