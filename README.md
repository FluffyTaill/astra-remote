# Astra Remote

Плагин для [Astra](https://github.com/mihailinl/AstraPlugins) и Android-приложение к нему: управляй ПК и говори
с Astra с телефона.

В приложении пять вкладок:

- **Пульт** — загрузка ПК, что сейчас играет, назад / пауза / дальше, громкость и звук, до 12 своих кнопок.
  Кнопка запускает команду Astra, которую ты на неё повесил: открыть сайт, запустить программу, сказать фразу…
- **Чат** — разговор с Astra, ответ появляется по мере написания.
- **Файлы** — общая папка на ПК: отправить файлы с телефона, забрать любой файл из папки, файлы, которые
  прислала Astra. Отправить на ПК можно и из любого приложения: «Поделиться» → Astra Remote.
- **Экран** — снимок экрана ПК (с автообновлением раз в 3 с), любой из мониторов.
- **Ещё** — блокировка, выключение монитора, сон; выключение и перезагрузка, если разрешены; общий буфер обмена
  (текст в обе стороны); блокировка приложения; отключение телефона.

Ссылку, которой поделились с Astra Remote, можно открыть в браузере на ПК, положить в буфер ПК или отправить Astra.

## Как это устроено

```
Телефон (приложение)  ⇄  HTTPS в домашней сети или Tailscale  ⇄  плагин на ПК  ⇄  Astra
```

Astra не открывает ничего в сеть, а плагину доступен только `PluginHostService` (токен плагина к другим
сервисам демона не подходит). Поэтому плагин сам поднимает небольшой сервер. Медиаклавиши, громкость, снимок
экрана, буфер обмена, файлы и питание он делает сам через Windows. От Astra ему нужны `SendChatMessage` для чата,
`FireTrigger` для кнопок, и он даёт Astra два инструмента:

- `send_file_to_phone` — «скинь мне на телефон отчёт из Загрузок»: Astra копирует файл или папку в общую папку,
  и он появляется в приложении во вкладке «Файлы»;
- `list_phone_uploads` — «что я прислал с телефона?»: список полученных файлов с полными путями.

## Установка

1. Astra → Мастерская → Разработка → Импорт плагина → `astra-remote.astraplugin`. Подтверди разрешения.
2. Поставь `android/astra-remote.apk` на телефон (Android 8+): перекинь файл на телефон и открой,
   Android попросит разрешить установку из этого источника.
3. В Astra открой страницу **Astra Remote** и нажми **«Подключить телефон»**.
4. В приложении нажми «Сканировать QR-код», наведи камеру на код. На ПК появится запрос с 4-значным кодом —
   нажми «Разрешить», если он совпадает с кодом на телефоне.

Если телефон не подключается: Windows спросит, пускать ли Node.js в сеть — разреши для **частных** сетей.
Если вопрос уже был отклонён: «Брандмауэр Защитника Windows» → «Разрешить взаимодействие с приложением» → Node.js.

### Вне дома

Дома приложение ходит к ПК напрямую, вне дома — через **твой собственный ретранслятор** на Cloudflare
(бесплатно, разворачивается в один клик — см. [relay/README.md](relay/README.md); общего нет). Ретранслятор
только передаёт байты: внутри та же защищённая связь с ПК (HTTPS с сертификатом из QR-кода), так что он не
видит ни команд, ни файлов, ни чата. Порт на ПК открывать не нужно, Tailscale ставить не нужно. Адрес
ретранслятора сохраняется на странице Astra Remote в Astra (карточка «Вне дома»).

Подключать телефон в первый раз нужно дома, в одной сети с ПК: после этого он сам узнаёт ретранслятор.
Tailscale по-прежнему работает, если он у тебя есть.

ПК должен быть включён и не спать: в настройках плагина включи «Не уходить в сон, пока подключён телефон»
(экран гаснет как обычно). Разбудить спящий ПК через интернет нельзя.

## Кнопки

На странице плагина подпиши кнопку (можно со значком-эмодзи). Затем Astra → **Команды** → новая команда,
триггер — **«Astra Remote: кнопка N на телефоне»**. Кнопка «Проверить» на странице плагина запускает её с ПК.
Команды Astra читает при старте, поэтому новая команда может появиться после перезапуска Astra.

## Общая папка

По умолчанию `%USERPROFILE%\Astra Remote` (меняется в настройках плагина):

- `С телефона` — сюда приходят файлы с телефона; имя никогда не перезаписывает существующий файл;
- `Для телефона` — сюда Astra копирует то, что отправляет на телефон.

Телефон видит только эту папку: пути проверяются на ПК, в том числе после перехода по ссылкам и ярлыкам папок.
Файлы с телефона сохраняются в «Загрузки/Astra Remote».

## Безопасность

- Связь — HTTPS с собственным сертификатом ПК. Приложение доверяет только сертификату, отпечаток которого пришёл
  в QR-коде, поэтому подменить ПК в сети нельзя. Ключ телефона уходит только после проверки сертификата.
- Сервер принимает подключения только из домашней сети и Tailscale; адреса из интернета отбрасываются до TLS.
- Подключение — только по одноразовому QR-коду со страницы плагина (живёт 5 минут, подходит одному телефону)
  и только после «Разрешить» на ПК. На ПК хранится только хеш ключа.
- У каждого телефона свой ключ; «Отключить» на странице плагина сразу закрывает доступ. Ключ действует
  90 дней (меняется в настройках, 0 — бессрочно), потом телефон подключается заново.
- В приложении ключ зашифрован ключом из Android Keystore и не попадает в резервные копии. Через минуту в фоне
  приложение блокируется (отпечаток, лицо или PIN телефона); экран приложения не попадает в скриншоты и
  список недавних.
- Выключение и перезагрузка по умолчанию запрещены; если разрешены — на ПК появляется окно «Разрешить?»,
  без ответа за минуту это отказ. Само выключение — через минуту (отмена с телефона).
- После 10 неудачных попыток с одного адреса он блокируется на 10 минут; частота запросов ограничена.
- Чат, снимок экрана, файлы, буфер, ссылки, питание — каждое можно выключить в настройках плагина.
- Журнал действий — на странице плагина и в `%APPDATA%\astra-remote\actions.log`. Текст чата и буфера туда
  не пишется.

Данные плагина (устройства, кнопки, журнал, сертификат) лежат в `%APPDATA%\astra-remote\`.

## Сборка

```bash
npm install
node build.js
npm test
```

Получится `astra-remote.astraplugin`.

Приложение собирается без Gradle (нужны Android SDK с `build-tools` и `platforms;android-35` и JDK 17+):

```bash
node android/build.js
```

Получится `android/astra-remote.apk`. При первой сборке создаётся ключ подписи `android/release.keystore`
и `android/keystore.properties` — сохрани оба: обновление приложения должно быть подписано тем же ключом.

## Файлы

- `src/index.ts` — плагин: триггеры кнопок, чат, инструменты для Astra, страница в Astra.
- `src/server.js` — сервер для телефона: сопряжение, ключи, ограничения, API.
- `src/files.js` — общая папка: список, приём и выдача файлов, отправка файлов от Astra.
- `src/pc.js` — что плагин делает на ПК сам: медиа, громкость, снимок экрана, буфер, ссылки, питание.
- `src/store.js` — устройства, кнопки, журнал.
- `ui/` — страница плагина в Astra.
- `android/` — приложение: `assets/index.html` (экраны), `src/…/Bridge.java` (вся сеть: закреплённый
  сертификат, ключ из `Vault`), `ScanActivity.java` (сканер QR на ZXing), `MainActivity.java` (блокировка,
  «Поделиться»), `build.js`.
